# Modelo — Ponto de Virada

**Habilidade treinada:** reavaliar.
Hipótese montada, dado novo chega, a estratégia precisa mudar.

| Bloco | Neste formato |
|---|---|
| `NARRATIVA` | padrão |
| `PERGUNTA` | padrão — a decisão inicial, com a hipótese ainda de pé |
| `NOVO DADO` | padrão — o dado que vira o caso |
| `REAVALIAÇÃO` | padrão — "o que muda agora?" |
| `CONFIANÇA` | padrão |
| `FEEDBACK` | padrão |
| `sedução:` nas alternativas | padrão |
| `LEVE DESTE CASO` | padrão |
| `PISTAS` | se o caso pedir |
| `CUSTO DO ATRASO` | se o caso pedir |
| `MÍDIA` | se o caso pedir |

## O que faz este formato funcionar

A primeira pergunta precisa ter uma resposta **correta no momento em que é feita**.
Se o aluno já puder desconfiar do desfecho, não existe virada — existe pegadinha.

A força do caso está na distância entre as duas respostas: o que era certo antes
do `NOVO DADO` e o que passa a ser certo depois dele.

Use `CONFIANÇA` nas duas perguntas. O dado mais interessante do ClinAct é o aluno
que respondeu a primeira com alta confiança e mudou de ideia na segunda.
