## 4. Temas usados mais de uma vez

Nenhum: os 100 temas são todos distintos — cada questão do simulado cobre um assunto diferente, sem repetição de conteúdo.

Pares de temas com nomes parecidos, mas **clinicamente distintos** (não devem ser unificados): *Colecistite aguda* x *Colangite aguda*; *Sífilis na gestação* x *Sífilis congênita*; *Rastreamento do câncer de colo uterino* x *Rastreamento do câncer colorretal*; *Profilaxia pós-exposição ao sarampo* x *Profilaxia pós-exposição antirrábica*.
